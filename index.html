Le problème

Aujourd'hui, plusieurs outils. Demain, un seul.

Le PI Planning L'Oréal R&I mobilise 100–150 personnes sur plusieurs jours. La coordination repose sur une pile d'outils qui n'ont pas été conçus pour ça.

Aujourd'hui

Plusieurs outils + des emails

❌Klaxoon - sessions live qui disparaissent après le PI. Aucune traçabilité.
❌Excel - plusieurs versions circulent, personne ne sait laquelle est la bonne.
❌Confluence - bilan rédigé des semaines après, reconstitué de mémoire.
❌Zéro visibilité pour les décideurs pendant le PI - le cockpit, c'est le tableau blanc.
→
Avec acCordance

Un outil, tout le cycle

✅Wizard guidé - configuration du PI en une fois : équipes, agenda, participants.
✅Jour J temps réel - dashboard live, vote de confiance instantané.
✅Breakout équipes - objectifs liés aux risques et aux dépendances, dans un seul écran.
✅Bilan immédiat - roadmap et analytics disponibles dès la fin du PI.
Le pain point n°1

Le lien avec ServiceNow

Aujourd'hui, la synchronisation entre Klaxoon et ServiceNow se fait entièrement à la main - c'est le point de friction le plus concret pour les PO/PTL.

Aujourd'hui

Tout à la main

❌Copier-coller manuel - le PO/PTL retranscrit à la main les objectifs de Klaxoon vers ServiceNow.
❌Mise à jour rétrospective - retrouver les Post-its Klaxoon un par un pour retracer l'avancement réel.
acCordance
Avec acCordance

Un échange direct

✅Lien natif - référence externe ServiceNow sur chaque objectif ; export Excel acCordance directement ingérable par ServiceNow.
✅Avancement à jour, au choix - copier-coller, import Excel, ou édition directe dans acCordance.
